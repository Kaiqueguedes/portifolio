# Portfólio — Kaique Guedes

Site pessoal com apresentação, habilidades, projetos e contato. HTML, CSS e JavaScript puros, sem dependências.

**No ar:** https://kaiqueguedes.github.io/portifolio/

## Páginas

| Arquivo | Conteúdo |
| :--- | :--- |
| `index.html` | Home: apresentação, sobre mim, projetos em destaque e chamada para contato |
| `skills.html` | Linguagens, dados, ferramentas, conceitos e soft skills |
| `projects.html` | Projetos com filtro por categoria (Dados / Web) |
| `contact.html` | Canais de contato e formulário que abre o e-mail |

## Recursos

- Tema escuro e claro, com a escolha guardada no navegador.
- Fundo animado em rede de partículas, que reage ao mouse.
- Cartões com efeito de vidro, brilho e inclinação em 3D.
- Efeito de digitação, barra de progresso de rolagem e faixa de tecnologias.
- Layout responsivo, com menu próprio para telas pequenas.
- Respeita a preferência do sistema por menos movimento.

## Como rodar

Basta abrir o `index.html` no navegador. Não há build nem instalação.

## Estrutura

```
portifolio/
├── index.html
├── skills.html
├── projects.html
├── contact.html
├── style.css      # toda a aparência, em variáveis CSS
├── main.js        # tema, animações e formulário
├── favicon.svg
└── Curriculo-Kaique-Guedes.pdf
```

As cores ficam nas variáveis do topo do `style.css` (`--a`, `--b`, `--c`), fáceis de trocar.
